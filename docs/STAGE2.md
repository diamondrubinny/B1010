# שלב 2 — מנוע הסיפור, חיפוש חפצים, זוגות זיכרון, סולם רמזים ✅ הושלם

## מטרה
להחליף את מסך ה-placeholder במשחק שאפשר לשחק בו: פרק 0 (הדרכה) ופרק 1 (המאפייה) מתוך
"The Lantern of Willowbrook", כולל שמירת התקדמות, רמזים והתאמת קושי.

## מה נבנה
| רכיב | תיאור |
|---|---|
| מודל תוכן (JSON) | `assets/cases/lantern.json`: פרקים, צעדים (`narration`, `hiddenObject`, `memoryMatch`, `reward`), פריטים |
| `ContentValidator` | ולידציה בטעינה ובבדיקות: מזהים ייחודיים, גבולות כמות, אורך טקסט, **מילים אסורות** (steal, thief, police, dead, scary…) לפי העיקרון הקליני "אין גניבות" |
| `HiddenObjectEngine` | פריטים ברשת קבועה (אותו סידור בכל פעם, כי עקביות עוזרת לזיכרון). בחירה שגויה מקבלת תגובה עדינה ולא "טעות" |
| `MemoryMatchEngine` | 4/6/8 קלפים לפי קושי. אי-התאמה נשארת גלויה זמן ארוך ונהפכת בעדינות |
| `HintLadder` | 5 רמות: אין, תזכורת של Marmalade, רמז מילולי, הדגשת התשובה, העברת הפוקוס לתשובה. מתקדם עם הזמן, עם "Help me" ועם בחירות שגויות |
| `DifficultyAdapter` | מצב AUTO: מתחיל ב-Gentle, ועובר ל-Standard רק אחרי 3 פעילויות ברצף בלי רמזים |
| `ProgressRepository` | שמירה אחרי כל צעד, לכל שחקן. נמחקת יחד עם השחקן |
| מסך Chapter Player | תזכורת "Welcome back, last time…", צעדים, "What are we doing?", "Help me", Back שואל לפני יציאה |
| Case Files | רשימת פרקים: הושלם / הבא בתור. הפעלה חוזרת לא משנה את ההתקדמות |
| `docs/ART_PROMPTS.md` | רשימת prompts לאיורי AI של פרקים 0–1 |

## Placeholder עד שיגיעו האיורים
- חפצים: אימוג'י של המערכת עם תווית טקסט (קריאה ותמונה יחד).
- רקעי סצנה: גרדיאנט רגוע עם שם המקום.
- אם קיים איור בשם `obj_<id>`, `scene_<id>` או `char_<id>`, הוא מוצג אוטומטית במקום ה-placeholder.

## מחוץ לתחום (שלב 3)
קריינות (TTS ו-AI voice), צלילים, ופעילויות `CLUE_RECALL`, `SPELL_SEQUENCE`, `SORTING` ו-`PICTURE_RIDDLE`.

## בדיקות
- יחידה: מנועים, סולם רמזים, קושי, ולידציה של קובץ התוכן האמיתי, ושמירת התקדמות.
- UI (Robolectric): משחק מלא של פרק 0 ופרק 1 בשלט בלבד, כולל צילומי מסך.
